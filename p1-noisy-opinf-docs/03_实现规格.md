## 3. 随机数（`seeds.py`）

主种子 `MASTER_SEED = 20261029`。**所有**随机数都通过

```python
def rng(*keys: int) -> np.random.Generator:
    return np.random.default_rng([MASTER_SEED, *keys])
```

获得。键的约定：

| 用途 | keys |
|---|---|
| 初始条件 | `(system_id, split_id, traj_index)`，其中 system_id：S1=1，S2=2，S3=3；split_id：train=1，val=2，test=3 |
| 噪声 | `(system_id, 4, experiment_id, rho_index, replicate, traj_index)`，同一个 split 内每条轨迹一个子流；验证集噪声 `split` 偏移 100 |
| S1 中求 O_true 的随机点 | `(1, 9)` |

不同 `n_train` 必须是**嵌套**的：`n_train=10` 的轨迹是 `n_train=30` 的前 10 条。所以训练轨迹按 index 0,1,2,... 生成，取前缀。

## 4. 系统规格

### 4.1 S1：Galerkin–Burgers 精确二次离散系统（`systems/galerkin_burgers.py`）

**目的：** 一个降阶动力学**恰好是二次**的离散系统，$O_{\text{true}}$ 已知，用来干净地检验理论。

- 区域 $[0,1)$，周期。实值 Fourier 基，$M$ 个波数，$r=2M$：
  $\varphi_{2(m-1)}(x)=\sqrt2\cos(2\pi m x)$，$\varphi_{2(m-1)+1}(x)=\sqrt2\sin(2\pi m x)$，$m=1,\dots,M$。
  在 $L^2(0,1)$ 中标准正交。不含常数模态（Burgers 保持均值，初值均值为 0）。
- 默认 $M=4$（$r=8$），$\nu=0.02$，步长 $h=0.005$。
- 求积网格 $N_g=64$，$x_j=j/N_g$。$\Phi\in\mathbb R^{N_g\times r}$，第 $i$ 列为 $\varphi_i(x_j)$；$\Phi_x$ 为解析导数。
- 连续时间右端：
  $$f(q)=Lq+\mathcal N(q),\quad L=\text{diag}\big(-\nu(2\pi m_i)^2\big),\quad \mathcal N(q)=\tfrac{1}{N_g}\Phi^\top\big[-(\Phi q)\odot(\Phi_x q)\big].$$
  （$N_g=64>3M$，三角多项式的求积是精确的，$\frac1{N_g}\Phi^\top\Phi=I$。）
- **离散映射（显式 Euler）：** $F(q)=q+h\,f(q)$。这是一个**精确**的二次映射：$A=I+hL$，$H=h\cdot(\mathcal N\text{ 的系数})$，$c=0$。
- $O_{\text{true}}$ 的计算：在 `rng(1, 9)` 生成的 $5p$ 个标准正态随机点上计算 $F$，用 OLS 拟合，**断言**残差最大绝对值 < 1e-11，并断言 $c$ 的范数 < 1e-12。
- 初值：$q_{0,2(m-1)},\,q_{0,2(m-1)+1}\sim\mathcal N(0,(0.5/m)^2)$。
- 轨迹长度：$K=300$ 步（301 个快照）。
- 每条轨迹生成后检查 $\max|u|$（在网格上）< 5 且全部有限，否则用下一个 index 重抽，并记录被跳过的 index。（预期不会触发。）
- 预检参考值（文档作者用幅度 0.6/m、K=400 试跑 20 条）：$\max|u|\approx3.7$；非线性项与线性项范数之比的中位数约 0.52；$q^\top\mathcal N(q)$ 的相对值 < 1e-15；终态范数约为初值的 7%。改为 0.5/m、K=300 后应更温和。

### 4.2 通用 ETDRK4 求解器（`systems/spectral.py`）

求解周期区域 $[0,1)$ 上的 $u_t=\mathcal Lu+\mathcal N(u)$，$\mathcal L$ 在 Fourier 空间中是对角的。

- 网格 $x_j=j/N$；波数 `k = 2*np.pi*np.fft.rfftfreq(N, d=1.0/N)`；
- 去混叠：2/3 规则，`mask = np.abs(np.fft.rfftfreq(N, d=1.0/N)) < N/3`（用整数波数比较）；
- 非线性项（两个系统相同）：$\mathcal N(u)=-\tfrac12(u^2)_x$，在 Fourier 空间为
  `Nhat(v) = -0.5j * k * mask * rfft(irfft(v, N)**2)`；
- Kassam–Trefethen ETDRK4 系数，围道点数 $M_c=32$：
  ```python
  Lh = dt * Lk                                   # Lk: 复数数组（KdV 时有虚部）
  E, E2 = np.exp(Lh), np.exp(Lh/2)
  rr = np.exp(1j*np.pi*(np.arange(1, Mc+1) - 0.5)/Mc)
  LR = Lh[:, None] + rr[None, :]
  Q  = dt*np.mean((np.exp(LR/2) - 1)/LR, axis=1)
  f1 = dt*np.mean((-4 - LR + np.exp(LR)*(4 - 3*LR + LR**2))/LR**3, axis=1)
  f2 = dt*np.mean((2 + LR + np.exp(LR)*(-2 + LR))/LR**3, axis=1)
  f3 = dt*np.mean((-4 - 3*LR - LR**2 + np.exp(LR)*(4 - LR))/LR**3, axis=1)
  # 若 Lk 为实数，对 Q,f1,f2,f3 取 .real
  ```
  单步：
  ```python
  Nv = Nhat(v); a = E2*v + Q*Nv; Na = Nhat(a)
  b = E2*v + Q*Na; Nb = Nhat(b)
  c = E2*a + Q*(2*Nb - Nv); Nc = Nhat(c)
  v = E*v + Nv*f1 + 2*(Na + Nb)*f2 + Nc*f3
  ```
- 接口：`solve(u0, Lk, dt, n_sub, n_obs) -> U`，返回形状 $(n_{\text{obs}}+1, N)$ 的实数数组，包含初值。每 `n_sub` 个内部步保存一次。

### 4.3 S2：粘性 Burgers（`systems/burgers.py`）

$u_t+uu_x=\nu u_{xx}$，即 $\mathcal L(k)=-\nu k^2$。

| 参数 | 默认值 |
|---|---|
| $N$ | 256 |
| $\nu$ | 0.01 |
| 内部步长 dt | $2.5\times10^{-4}$ |
| 观测间隔 $\Delta t_{\text{obs}}$ | 0.005（`n_sub = 20`） |
| 观测步数 $K$ | 200（总时间 1.0） |
| 初值 | $u_0(x)=0.5\sum_{m=1}^{3}\frac{g_m}{m}\sin(2\pi mx+\phi_m)$，$g_m\sim\mathcal N(0,1)$，$\phi_m\sim U(0,2\pi)$ |

**分辨率验收（E0 中执行，正式实验前必须通过）：** 取 5 条训练初值，用 $(N, dt)$ 与 $(2N, dt/2)$ 分别求解（细网格解在粗网格点上取样比较），所有观测时刻的相对 $L^2$ 差的最大值 < $10^{-4}$。不通过时按以下顺序调整，**每次只改一项**，并在 `PROGRESS.md` 中记录：
1. $N\to512$；
2. dt 减半；
3. 初值幅度 0.5 → 0.4。

### 4.4 S3：KdV–Burgers（`systems/kdv_burgers.py`）

$u_t+uu_x=\nu u_{xx}-\delta u_{xxx}$，即 $\mathcal L(k)=-\nu k^2+i\delta k^3$。

| 参数 | 默认值 |
|---|---|
| $N$ | 512 |
| $\nu$ | 0.005 |
| $\delta$ | $1\times10^{-5}$ |
| dt | $1\times10^{-4}$ |
| $\Delta t_{\text{obs}}$ | 0.005（`n_sub = 50`） |
| $K$ | 200 |
| 初值 | 与 S2 相同的形式，幅度 0.5 |

**验收：**
1. 分辨率验收：同 S2，但阈值放宽为 $10^{-3}$（色散项使得收敛误差约在 $2\text{–}3\times10^{-4}$，与 N 无关，主要来自时间离散）；
2. 非平凡性：$t=1$ 时 $\|u\|_2/\|u_0\|_2>0.2$（中位数，5 条轨迹）；
3. 与 S2 不同：S3 的 POD 能量谱（取 99% 能量所需的秩）应与 S2 不同。只需要报告这个值，不设阈值。

不通过时依次尝试：dt 减半；$\nu\to0.006$；$N\to1024$。每次只改一项并记录。

**预检参考值**（文档作者在 Linux 上用同一算法试跑 5 条轨迹）：

| 系统 | 参数 | 收敛误差 | $t=1$ 范数比 | $\max|u|$ | POD 秩（99% / 99.9% / 99.99% 能量） |
|---|---|---|---|---|---|
| S2 | N=256, ν=0.01, dt=2.5e-4 | 8.9e-7 | 0.35 | 1.61 | 8 / 13 / 18 |
| S3 | N=512, ν=0.005, δ=1e-5, dt=1e-4 | 3.0e-4 | 0.44 | 1.70 | 17 / 33 / 49 |

注意：$\nu=0.002,\ \delta=2\times10^{-5}$ 在 N=512 和 1024 下都会**发散**（NaN），不要使用。
你的实现应得到同量级的数值；若差别超过一个数量级，先检查实现。**参数确定后，在开始任何估计器实验前固定，之后不再修改。**

## 7. POD（`pod.py`）

```python
def pod_basis(snapshots_list: list[np.ndarray], r: int) -> tuple[np.ndarray, np.ndarray]
    # 把所有训练快照按列拼接成 (N, K_tot)，不中心化，用 np.linalg.svd(full_matrices=False)。
    # 返回 V (N, r) 与全部奇异值。
def project(U: np.ndarray, V) -> np.ndarray          # (K+1, N) -> (K+1, r)
def estimate_sigma2(noisy_snapshots_list, method="trailing_median"|"gavish_donoho") -> tuple[float, dict]
```

**基与参考算子必须一致（重要）：**

- `basis="clean"`：$V$ 由干净训练快照计算。参考 $O_{\text{ref}}=O_{\text{clean}}$ 是干净训练轨迹在 $V$ 上投影后的 OLS。
- `basis="noisy"`：$\hat V$ 由带噪训练快照计算。参考 $O_{\text{ref}}$ 是**干净**训练轨迹在 $\hat V$ 上投影后的 OLS（同一个基）。

因此每个噪声重复都要重新算参考算子。预测误差总是在全阶空间中与真解比较，不依赖基。

## 9. 估计器（`estimators.py`）

```python
@dataclass
class FitResult:
    O: np.ndarray                 # (p, r)，原坐标
    method: str
    n_pairs: int
    kappa: float
    lam: float | None
    diagnostics: dict             # gram_min_eig, gram_cond, n_clipped, first_stage_F 等

```

- `ridge` 的 λ 由调用方（实验脚本）在验证集上选好后传入。
- `iv`/`iv2` 的诊断：第一阶段对每个回归量的 $R^2$ 中位数，以及 $W^\top\tilde Z$ 的条件数。
- 如果某个矩阵求解失败（`LinAlgError`），返回 `FitResult` 时把 `O` 设为全 NaN，并在 `diagnostics["error"]` 中写明原因，**不要抛出异常中断整个网格**。

## 14. 性能要求

- 估计器单次拟合：r=8、n_pairs≈6000 时，`mc` 应 < 1 秒；r=16 时应 < 10 秒。超出时先优化 `hermite_monomial_sums`（预先按 $\alpha$ 去重，并对坐标幂做缓存）。
- 每个实验脚本开始时，先运行 1 个配置并计时，**按网格大小估算总耗时**，写进日志。估算超过 4 小时就先报告，按 `04` 中规定的缩减规则缩减。
- 用 `joblib` 在（配置 × 重复）层面并行，`n_jobs = max(1, os.cpu_count() - 1)`。每个子进程设置 `OMP_NUM_THREADS=1`、`MKL_NUM_THREADS=1`、`OPENBLAS_NUM_THREADS=1`，避免过度订阅。
