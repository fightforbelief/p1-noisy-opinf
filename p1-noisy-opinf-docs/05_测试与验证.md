# 05 测试与验证（`tests/`，用 pytest）

**所有测试必须在跑任何正式实验（E1 及以后）之前通过。** 每个测试用小规模数据，整套测试在远程机器上应在 3 分钟内跑完。随机测试使用固定种子。

## 1. 特征（`test_features.py`）

| 测试 | 断言 |
|---|---|
| `test_quad_index_order` | r=3 时，`quad_index` 等于 `[(0,0),(0,1),(0,2),(1,1),(1,2),(2,2)]` |
| `test_feature_values` | 对随机 q（r=4），`features(q)` 的每一项等于手算的 $q_i$、$q_iq_j$、1 |
| `test_exponents_match_features` | 对随机 q，$\prod_c q_c^{e_{a,c}}$ 等于 `features(q)[a]`，对所有 a 成立 |
| `test_diag_rows` | `diag_quad_rows(r)` 对应的特征等于 $q_i^2$ |

## 2. Hermite（`test_hermite.py`）

| 测试 | 断言 |
|---|---|
| `test_hermite_unbiased_1d` | 对 n=0..4、q ∈ {−1.3, 0, 0.7}、s²=0.3，用 $10^6$ 个噪声样本的均值 $E[\mathrm{He}_n(q+\varepsilon)]$ 与 $q^n$ 的差 < 5 倍蒙特卡洛标准误 |
| `test_hermite_unbiased_multivariate` | r=3，随机 q，所有次数 ≤ 4 的 α，同上 |
| `test_corrected_gram_unbiased` | 固定的 50 个干净点（r=3），对 2000 次噪声重复取 `hermite_monomial_sums` 构造的 $\hat G$ 的平均值，与干净 $Z^\top Z$ 的相对 Frobenius 差 < 1% |
| `test_corrected_cross_unbiased` | 同上，检验 $\hat C$ 与干净 $Z^\top Y$ 的差 < 1%（Y 用另一组独立噪声的下一时刻） |
| `test_expected_monomial` | `expected_monomial` 与 $10^6$ 样本的经验均值一致（< 5 SE） |

## 3. 估计器（`test_estimators.py`）

构造一个小的**精确二次**随机系统用于测试：r=3，随机 A（谱半径 0.9），随机小 H（缩放到使轨迹有界），c 随机小量；从 20 个随机初值各生成 100 步。（如果发散，就缩小 H 重来，测试里固定好缩放系数。）

| 测试 | 断言 |
|---|---|
| `test_ols_exact_recovery` | 无噪声时 `ols` 恢复真算子，相对误差 < 1e-10 |
| `test_all_methods_noise_free` | σ²=0 时 `mc`、`mc_psd`、`iv`、`iv2` 都恢复真算子（< 1e-8） |
| `test_scaling_invariance` | 对数据乘以 1000 再拟合（并相应调整真算子：A 不变，H/1000，c·1000），与直接拟合的结果一致（< 1e-8） |
| `test_mc_consistency` | σ = 0.05·RMS(q)，n 从 2000 增加到 50000 时，`mc` 的误差下降（中位数，10 次重复）；在 n=50000 时 < `ols` 误差的 1/2 |
| `test_iv_consistency` | 同上，对 `iv` 和 `iv2` |
| `test_iv_intercept_correction` | 关闭常数修正（内部开关）时，$\hat c$ 的偏差接近 $-O^\top\mu$（< 10% 相对差，n=50000）；打开修正后偏差消失 |
| `test_ridge_lambda_zero` | `ridge` 在 λ=1e-12 时等于 `ols`（< 1e-6） |
| `test_singular_returns_nan` | 构造秩亏的数据，`fit` 返回全 NaN 的 O，且 `diagnostics["error"]` 非空，不抛异常 |
| `test_pairs_do_not_cross_trajectories` | 两条轨迹首尾拼接的错误对不出现在 Z/Y 中（构造特殊数据检查） |

另有 `test_reference_values.py`：复现 `02` 第 3.6 节的预验证设置，按该节给出的容差断言。

## 4. 理论（`test_theory.py`）

| 测试 | 断言 |
|---|---|
| `test_ols_limit_zero_noise` | σ²=0 时 `ols_limit` 等于干净 OLS（< 1e-10） |
| `test_linear_attenuation` | 只用线性特征的版本：`ols_limit` 等于 $AM(M+\sigma^2I)^{-1}$（< 1e-10） |
| `test_ols_limit_matches_mc` | 上面的小系统，n = 20000，σ=0.05·RMS，200 次重复的 OLS 均值与 `ols_limit` 的差 < 偏差大小的 10% |
| `test_mc_limit_ar1` | φ=0.5，同上的蒙特卡洛对照，差 < 偏差大小的 10% |

## 5. 噪声与 POD（`test_noise_pod.py`）

| 测试 | 断言 |
|---|---|
| `test_white_noise_stats` | 方差在 1% 以内 |
| `test_ar1_stats` | 边际方差（1%）和滞后 1 自相关（±0.02） |
| `test_projected_noise_isotropic` | 给定正交 V，$V^\top\eta$ 的样本协方差接近 $\sigma^2I_r$ |
| `test_sigma2_trailing` | 低秩信号（秩 5，N=128，K=2000）+ 噪声，`est_trailing` 的相对误差 < 5% |

## 6. 系统（`test_systems.py`）

| 测试 | 断言 |
|---|---|
| `test_galerkin_orthonormal` | $\frac1{N_g}\Phi^\top\Phi=I$（< 1e-14） |
| `test_galerkin_energy_conserving` | 随机 q：$|q^\top\mathcal N(q)|<10^{-12}\|q\|^3$ |
| `test_galerkin_exact_quadratic` | `O_true` 的拟合残差 < 1e-11 |
| `test_etdrk4_linear_exact` | 关闭非线性项（`Nhat ≡ 0`）时，ETDRK4 对单 Fourier 模态的解与解析解 $e^{L t}$ 一致（< 1e-10） |
| `test_etdrk4_order` | Burgers，N=256，一条轨迹，积分到 t=0.2。以 dt/32 的解为参照，分别计算 dt=1e-3、5e-4、2.5e-4 的误差；相邻误差比约为 16（在 10–22 之间）。若误差已降到 1e-12 附近（舍入误差主导），则改用更大的 dt 起点 |
| `test_burgers_mean_conserved` | 空间均值守恒（< 1e-12） |

## 7. 端到端冒烟测试（`test_smoke.py`）

用 S2、r=4、n_train=3、K=40、rho=0.05、R=1 跑一遍完整的 E3 流程（所有估计器），断言：生成了 `runs.csv`，列名与 `03` 第 13 节一致，没有意外的 NaN（`status` 为 `ok` 的行中，指标列无 NaN）。

## 8. 每个实验脚本的自检

每个实验脚本结束时自动检查并在日志中打印：
- 行数是否等于（配置数 × 估计器数 × 重复数）；
- `status != "ok"` 的行数及原因；
- `rho = 0` 的行中，`ols`、`mc` 与 `oracle` 的差（应 < 1e-8）。

任何一项不符合，在 `PROGRESS.md` 中如实写明。
