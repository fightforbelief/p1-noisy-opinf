## 1. 特征映射与算子排布

### 1.1 二次特征

降阶状态 $q\in\mathbb R^r$。定义二次单项式向量

$$s(q) = \big(q_i q_j\big)_{0\le i\le j\le r-1}\in\mathbb R^{m},\qquad m=\frac{r(r+1)}{2},$$

**排列顺序固定为字典序**：外层 $i$ 从 0 到 $r-1$，内层 $j$ 从 $i$ 到 $r-1$。即 $(0,0),(0,1),\dots,(0,r-1),(1,1),(1,2),\dots,(r-1,r-1)$。

完整特征向量（长度 $p=r+m+1$）：

$$z(q) = \big[\,q_0,\dots,q_{r-1},\; s(q),\; 1\,\big]^\top\in\mathbb R^p .$$

实现要求：
- 提供 `quad_index(r) -> list[tuple[int,int]]`，返回上述顺序的 $(i,j)$ 列表；
- 提供 `diag_quad_rows(r) -> np.ndarray`，返回所有 $(i,i)$ 项在 $z$ 中的**行号**（即 $r+\text{pos}(i,i)$）；
- 提供**指数表** `exponents(r) -> np.ndarray[int]`，形状 $(p, r)$：第 $a$ 行是特征 $z_a$ 作为单项式 $\prod_c q_c^{e_{a,c}}$ 的指数向量。线性特征 $q_i$ 的指数是单位向量 $e_i$；$q_iq_j$ 的指数在 $i$ 和 $j$ 位置各加 1（$i=j$ 时该位置为 2）；常数特征的指数全为 0。

### 1.2 算子矩阵

离散时间二次模型：

$$q_{k+1} = A q_k + H s(q_k) + c = O^\top z(q_k),$$

其中 $O\in\mathbb R^{p\times r}$：**行对应特征，列对应输出分量**。

- $A = O[0{:}r,\,:]^\top\in\mathbb R^{r\times r}$
- $H = O[r{:}r+m,\,:]^\top\in\mathbb R^{r\times m}$
- $c = O[p-1,\,:]\in\mathbb R^{r}$

### 1.3 数据矩阵

对每条轨迹 $\{q_0,\dots,q_K\}$，取相邻对 $(q_k, q_{k+1})$，$k=0,\dots,K-1$。把所有训练轨迹的对堆叠起来：

- $Z\in\mathbb R^{n\times p}$，第 $k$ 行为 $z(q_k)^\top$；
- $Y\in\mathbb R^{n\times r}$，第 $k$ 行为 $q_{k+1}^\top$。

**相邻对不能跨轨迹。**

### 1.4 坐标缩放（数值稳定性，必须实现）

二次特征和线性特征的量级差异会使 Gram 矩阵病态。拟合前，用**一个标量** $\kappa>0$ 缩放全部降阶坐标（为保持噪声各向同性，不能逐分量缩放）：

$$y = q/\kappa,\qquad \kappa = \max_{k}\|q_k\|_\infty\ \ (\text{在训练数据上，带噪时用带噪数据}).$$

缩放后噪声方差为 $\sigma^2/\kappa^2$。在 $y$ 坐标中拟合得到 $(\tilde A,\tilde H,\tilde c)$ 后，换回原坐标：

$$A=\tilde A,\qquad H=\tilde H/\kappa,\qquad c=\kappa\,\tilde c.$$

（推导：$q_{k+1}=\kappa y_{k+1}=\kappa(\tilde Ay_k+\tilde Hs(y_k)+\tilde c)=\tilde A q_k+\tilde H s(q_k)/\kappa+\kappa\tilde c$，因为 $s(y)=s(q)/\kappa^2$。）

**所有估计器都在缩放坐标中计算，对外接口一律返回原坐标的 $O$。** 单元测试必须验证：缩放前后的估计结果一致（在无噪声、良态情形下，相对差 < 1e-8）。

## 2. 噪声模型

### 2.1 白噪声（主模型）

全阶状态 $u_k\in\mathbb R^N$ 的观测为 $\tilde u_k=u_k+\eta_k$，其中 $\eta_k\stackrel{iid}{\sim}\mathcal N(0,\sigma^2I_N)$，在时间、轨迹之间独立，且与 $u$ 独立。

POD 基 $V\in\mathbb R^{N\times r}$ 满足 $V^\top V=I_r$（**欧氏正交，不加网格权重**）。降阶坐标为

$$\tilde q_k=V^\top\tilde u_k=q_k+\varepsilon_k,\qquad \varepsilon_k=V^\top\eta_k\sim\mathcal N(0,\sigma^2 I_r).$$

当 $V$ 由干净数据计算时，上式严格成立；当 $V$ 由带噪数据计算时，只是近似成立（这正是 E3 要研究的因素之一）。

对于 S1（精确二次系统，没有全阶状态），噪声直接加在 $q$ 上：$\tilde q_k=q_k+\varepsilon_k$，$\varepsilon_k\stackrel{iid}{\sim}\mathcal N(0,\sigma^2I_r)$。

### 2.2 噪声水平的定义

相对噪声水平 $\rho_{\text{noise}}$（下文记为 `rho`）：

- S2/S3：$\sigma=\text{rho}\cdot\text{RMS}(u)$，其中 $\text{RMS}(u)=\sqrt{\text{mean}(u^2)}$，在**全部干净训练快照**上计算（对 $N$ 个网格点和全部时间求平均）。
- S1：$\sigma=\text{rho}\cdot\sqrt{\text{mean}_k\|q_k\|^2/r}$，在全部干净训练快照上计算。

`rho` 网格见 `04`。

### 2.3 AR(1) 时间相关噪声（只在 E8 使用）

$$\eta_0\sim\mathcal N(0,\sigma^2 I),\qquad \eta_k=\phi\,\eta_{k-1}+\sqrt{1-\phi^2}\,\xi_k,\quad \xi_k\stackrel{iid}{\sim}\mathcal N(0,\sigma^2 I).$$

边际方差恒为 $\sigma^2$，滞后 1 的相关系数为 $\phi$。每条轨迹独立生成。

## 3. 估计器

所有估计器的签名统一为（见 `03`）：

```python
fit(trajs: list[np.ndarray], method: str, sigma2: float | None, **kwargs) -> FitResult
```

其中 `trajs` 中每个元素是形状 $(K+1, r)$ 的降阶轨迹（带噪或干净）。

### 3.1 OLS / Ridge（基线）

$$\hat O_{\text{OLS}}=\arg\min_O\|Y-ZO\|_F^2+\lambda\|D^{1/2}O\|_F^2=(Z^\top Z+\lambda D)^{-1}Z^\top Y,$$

其中 $D=\text{diag}(1,\dots,1,0)$，**不惩罚常数项**。
- `ols`：$\lambda=0$。数值上用 `np.linalg.lstsq(Z, Y)` 求解，不要显式求逆。
- `ridge`：$\lambda$ 在验证集上从网格 $\{10^{-10},10^{-9},\dots,10^{2}\}$（13 个值）中选（选择准则见 `04` 第 1.4 节）。用增广最小二乘 `lstsq([Z; sqrt(λ) D^{1/2}], [Y; 0])` 求解。

### 3.2 Hermite 矩修正估计器（`mc`）

**引理（Hermite 无偏性）。** 设 $x=q+\varepsilon$，$\varepsilon\sim\mathcal N(0,s^2)$。定义方差为 $s^2$ 的概率论 Hermite 多项式：

$$\mathrm{He}_0=1,\quad \mathrm{He}_1(x)=x,\quad \mathrm{He}_2(x)=x^2-s^2,\quad \mathrm{He}_3(x)=x^3-3s^2x,\quad \mathrm{He}_4(x)=x^4-6s^2x^2+3s^4 .$$

则 $E[\mathrm{He}_n(q+\varepsilon;s^2)]=q^n$。

*证明思路（实现者不需要，负责人自己推）：* 生成函数 $\sum_n \mathrm{He}_n(x;s^2)t^n/n!=\exp(tx-s^2t^2/2)$，两边对 $\varepsilon$ 取期望即得 $e^{tq}$。

因为 $\varepsilon$ 的各分量独立，对于指数为 $\alpha\in\mathbb N^r$ 的单项式：

$$E\Big[\prod_{c}\mathrm{He}_{\alpha_c}(\tilde q_c;\sigma^2)\Big]=\prod_c q_c^{\alpha_c}=q^\alpha .$$

记 $\mathcal H_\alpha(\tilde q;\sigma^2):=\prod_c \mathrm{He}_{\alpha_c}(\tilde q_c;\sigma^2)$。它是 $q^\alpha$ 的无偏估计。

**修正的 Gram 矩阵。** $Z^\top Z$ 的元素 $(a,b)$ 是单项式 $q^{e_a+e_b}$（次数 ≤ 4）在所有样本上的和。定义

$$\hat G_{ab}=\sum_{k}\mathcal H_{e_a+e_b}(\tilde q_k;\sigma^2).$$

**修正的交叉矩。** 定义修正特征 $\hat z_k$，其第 $a$ 个分量为 $\mathcal H_{e_a}(\tilde q_k;\sigma^2)$。实际上只有对角二次特征会变化：$\tilde q_i^2\to\tilde q_i^2-\sigma^2$，其余分量与 $z(\tilde q_k)$ 相同。则

$$\hat C=\sum_k \hat z_k\,\tilde q_{k+1}^\top .$$

由于 $\varepsilon_{k+1}$ 与第 $k$ 时刻的一切独立且均值为零，$E[\hat C]=\sum_k z(q_k)q_{k+1}^\top$。

**估计量：**

$$\hat O_{\text{MC}}=\hat G^{-1}\hat C\qquad(\text{用 } \texttt{np.linalg.solve}).$$

> **pilot 代码的已知缺陷：** `reference/pilot_reference.py` 只修正了 Gram 矩阵，**没有修正交叉矩**（直接用了 $z(\tilde q_k)$）。正式实现必须使用上面的 $\hat z_k$。

**实现要求：**
- Gram 元素只依赖 $\alpha=e_a+e_b$。先枚举所有不同的 $\alpha$（次数 ≤ 4），每个 $\alpha$ 只计算一次 $\sum_k\mathcal H_\alpha(\tilde q_k)$，再填入矩阵。
- 预先计算每个坐标的 $\mathrm{He}_0,\dots,\mathrm{He}_4$（形状 $(5,n,r)$）。$\mathcal H_\alpha$ 是最多 4 个非平凡因子的乘积。
- 在缩放坐标中计算，使用 $\sigma^2/\kappa^2$。
- 记录 $\hat G$ 的最小特征值和条件数到 `FitResult.diagnostics`。

**`mc_psd` 变体。** $\hat G$ 是无偏的，但不保证半正定。对 $\hat G=U\Lambda U^\top$，把特征值截断为 $\Lambda^+=\max(\Lambda,\ \delta\cdot\lambda_{\max})$，其中 $\delta=10^{-8}$，再求解 $\hat O=(U\Lambda^+U^\top)^{-1}\hat C$。记录被截断的特征值个数。

**MC-PSD 零噪声特例（E0 验收修订）。** 这是对上面定义的零噪声边界修订，正噪声下的估计器定义不变。当传入的噪声方差 $\sigma^2$ 严格等于 0 时，MC-PSD 直接使用未经谱截断的 Hermite 矩估计解，即与 `mc` 使用相同的 Gram 和交叉矩求解，此时 `n_clipped=0`。任何严格正的 $\sigma^2$ 仍使用 $\delta=10^{-8}$ 的相对谱截断，不把很小但非零的 $\sigma^2$ 当作 0，也不用条件数或其他近零阈值决定是否跳过截断。零噪声时若 Gram 不可逆，仍按既有失败协议返回 NaN，不伪造有限算子。

**`mc` 的一致性（供理解）：** 当样本量 $n\to\infty$，$\hat G/n\to\overline{zz^\top}$，$\hat C/n\to\overline{zq_+^\top}$（干净数据的样本矩）。所以 $\hat O_{\text{MC}}\to O_{\text{clean}}$。**这对任何动力学都成立，无论降阶模型是否精确为二次**（只需要噪声与时间独立且为高斯）。这是 RQ4 的核心对比点。

### 3.3 滞后工具变量估计器（`iv`, `iv2`）

**思想：** 噪声 $\varepsilon_k$ 污染了回归量 $z(\tilde q_k)$，但与前一时刻的 $\tilde q_{k-1}$ 无关（白噪声）。而前一时刻的特征与当前特征高度相关（动力学是光滑的）。所以 $w_k=z(\tilde q_{k-1})$ 是合格的工具变量。

**`iv`（恰好识别）：** 对每条轨迹取 $k=1,\dots,K-1$，令

- $\tilde Z$ 的行为 $z(\tilde q_k)^\top$，
- $W$ 的行为 $z(\tilde q_{k-1})^\top$，
- $\tilde Y$ 的行为 $\tilde q_{k+1}^\top$。

$$\hat O'_{\text{IV}}=(W^\top\tilde Z)^{-1}W^\top\tilde Y .$$

**`iv2`（两阶段最小二乘，过度识别）：** $k=2,\dots,K-1$，工具变量为

$$w_k=\big[\,z(\tilde q_{k-1})\text{ 去掉常数项},\ z(\tilde q_{k-2})\text{ 去掉常数项},\ 1\,\big]\in\mathbb R^{2p-1}.$$

第一阶段：$\hat Z=W\Pi$，其中 $\Pi=\texttt{lstsq}(W,\tilde Z)$。第二阶段：$\hat O'=\texttt{lstsq}(\hat Z,\tilde Y)$。

**常数项修正（两者都必须做）。** 由于 $E[z(\tilde q_k)]=z(q_k)+\mu$，其中 $\mu=\sigma^2\sum_i e_{\text{row}(i,i)}$（只有对角二次特征的位置为 $\sigma^2$），IV 一致估计的是 $A,H$ 以及**漂移后的**常数项 $c'=c-O^\top\mu$。因此输出前要修正：

$$\hat c=\hat c'+\sigma^2\sum_{i=0}^{r-1}\hat O'[\text{row}(i,i),\,:].$$

$A,H$ 不变。（`sigma2` 是必需参数；用估计的 $\hat\sigma^2$ 时用估计值。）

**IV 的估计目标（RQ4/H5，必须理解）：**

设 $O_{\text{IVc}}$ 是把同一个 IV 估计器（不做常数修正）用于**干净数据**得到的结果。可以证明，对白噪声，带噪 IV 加常数修正后的大样本极限就是 $O_{\text{IVc}}$。

- 若降阶动力学恰为二次（S1），$O_{\text{IVc}}=O_{\text{true}}=O_{\text{clean}}$；
- 若存在截断误差 $e_k=q_{k+1}-O_{\text{clean}}^\top z(q_k)$（S2/S3），OLS 残差与 $z(q_k)$ 正交，但一般与 $z(q_{k-1})$ **不正交**，所以 $O_{\text{IVc}}\ne O_{\text{clean}}$。

**实现要求：** 对每个 S2/S3 配置，额外计算并保存 $O_{\text{IVc}}$ 和 $O_{\text{IV2c}}$（在干净训练数据上运行 `iv`/`iv2`，不做常数修正），用于 E5。

### 3.4 Oracle

`oracle`：在干净训练轨迹上运行 `ols`，即 $O_{\text{clean}}$。

## 4. OLS 的大样本极限（RQ1，E1 的理论值）

### 4.1 高斯平移矩

对 $x=q+\varepsilon$，$\varepsilon\sim\mathcal N(0,s^2)$：

$$E[x^n]=\sum_{j\ \text{偶},\,0\le j\le n}\binom{n}{j}q^{n-j}s^{j}(j-1)!!,\qquad(-1)!!=1 .$$

当 $n\le4$ 时分别为：$1,\ q,\ q^2+s^2,\ q^3+3s^2q,\ q^4+6s^2q^2+3s^4$。

多元情形下，指数为 $\alpha$ 的单项式 $E[\tilde q^\alpha]=\prod_c E[\tilde q_c^{\alpha_c}]$。实现为 `expected_monomial(q, alpha, s2)`。

### 4.2 确定性等价极限

固定干净轨迹，对噪声取期望：

$$\bar G(\sigma^2)=\sum_k E\big[z(\tilde q_k)z(\tilde q_k)^\top\big],\qquad \bar G_{ab}=\sum_k E[\tilde q_k^{\,e_a+e_b}],$$

$$\bar C(\sigma^2)=\sum_k E[z(\tilde q_k)]\,q_{k+1}^\top=\sum_k\big(z(q_k)+\mu\big)q_{k+1}^\top .$$

$$O_{\text{lim}}(\sigma^2)=\bar G(\sigma^2)^{-1}\,\bar C(\sigma^2).$$

当 $n$ 很大时，带噪 OLS 的 Monte Carlo 均值应接近 $O_{\text{lim}}$。（这是"期望之比"近似。在大样本下它与 $\hat O_{\text{OLS}}$ 的概率极限一致。）实现为 `theory.ols_limit(clean_trajs, sigma2) -> O`。

### 4.3 纯线性特例（作为单元测试）

若只用线性特征（无二次项、无常数项），真实系统为 $q_{k+1}=Aq_k$，令 $M=\frac1n\sum_k q_kq_k^\top$，则

$$\hat A_{\text{OLS}}\to A\,M\,(M+\sigma^2 I)^{-1}.$$

这是经典的"回归稀释"（attenuation）。测试中验证 `ols_limit` 在只有线性特征时退化为此式。

## 5. 噪声方差 σ² 的估计

真实应用中 $\sigma^2$ 未知。估计器 `estimate_sigma2(S_noisy)`：

1. $\tilde S\in\mathbb R^{N\times K_{\text{tot}}}$ 为全部带噪训练快照（**不中心化**），要求 $K_{\text{tot}}\ge 2N$；
2. 计算 $\frac{1}{K_{\text{tot}}}\tilde S\tilde S^\top$ 的特征值 $\ell_1\ge\dots\ge\ell_N$；
3. 令 $\beta=N/K_{\mathrm{tot}}$，$\lambda_\pm=(1\pm\sqrt{\beta})^2$。Marchenko–Pastur 密度为

$$\rho_\beta(\lambda)=\frac{\sqrt{(\lambda_+-\lambda)(\lambda-\lambda_-)}}{2\pi\beta\lambda},\qquad \lambda\in[\lambda_-,\lambda_+].$$

$\mu_{\beta,0.25}$ 是该密度的 25% 分位数，由数值积分后求根得到。降序排列时，$\{\ell_i:i>N/2\}$ 的中位数落在噪声谱大约 25% 的分位上，因此

$$\hat\sigma^2_{\mathrm{trailing}}=\frac{\operatorname{median}\{\ell_i:i>N/2\}}{\mu_{\beta,0.25}}.$$

不把估计量改成全部特征值的中位数。

**适用前提：** 信号能量集中在远少于 $N/2$ 个方向上。实现时要检查并在诊断信息中记录：干净数据第 $N/2$ 个特征值与 $\sigma^2$ 之比（应 < 0.01）。

**备选（只在 E3 中做对比）：** Gavish–Donoho (2014) 的中位数奇异值法：$\hat\sigma=\text{med}(\text{sv}(\tilde S))/\sqrt{K_{\text{tot}}\,\mu_\beta}$，其中 $\beta=N/K_{\text{tot}}$，$\mu_\beta$ 是 Marchenko–Pastur 分布的中位数（数值积分求得）。

S1 没有全阶状态，σ² 的估计不适用，只用真实 σ²。

## 6. AR(1) 噪声下 MC 的偏差（E8 理论值）

在 2.3 节的模型下，每个时刻的边际分布仍是 $\mathcal N(0,\sigma^2 I)$，Hermite 修正只用同一时刻的坐标，所以 $E[\hat G]=\bar G_0$ 对任意有限配对数成立。第 3.2 节「$\varepsilon_{k+1}$ 与第 $k$ 时刻独立，因而 $E[\hat C]=\sum_k z(q_k)q_{k+1}^\top$」只适用于白噪声。AR(1) 下交叉矩 $E[\hat z_k\varepsilon_{k+1}^\top]$ 的二次块不为零。

令 $P$ 为进入 $\hat C$ 与 $\bar G_0$ 的全部配对输入状态：每条轨迹只包括 $k=0,\ldots,K-1$，不含该轨迹的末端快照，不跨轨迹配对。$n=|P|$。在干净坐标上定义

$$S_i=\sum_{k\in P}q_{k,i}.$$

$\Delta\in\mathbb R^{p\times r}$，行顺序与第 1.1 节的 $z(q)$ 相同：线性块、字典序二次块、常数块。记二次块为 $D_2(S)\in\mathbb R^{m\times r}$，则

$$\Delta=\begin{bmatrix}n\phi\sigma^2 I_r\\ D_2(S)\\ 0_{1\times r}\end{bmatrix}.$$

三个块分别是：

- **线性行** $i$、列 $b$：$\Delta_{i,b}=n\phi\sigma^2\delta_{ib}$。它来自 $E[\varepsilon_{k,i}\varepsilon_{k+1,b}]=\phi\sigma^2\delta_{ib}$，再对 $P$ 中的 $n$ 个配对求和。
- **二次行** $(i,j)$，$0\le i\le j\le r-1$，按第 1.1 节字典序放在行 $r+\mathrm{pos}(i,j)$，列 $b$：

$$\Delta_{(i,j),b}=\phi\sigma^2\big(\delta_{jb}S_i+\delta_{ib}S_j\big).$$

对角二次行是 $i=j$ 的同一式，系数为 2：

$$\Delta_{(i,i),b}=2\phi\sigma^2 S_i\delta_{ib}.$$

联合高斯的三阶矩只消去纯噪声项 $E[\varepsilon_i\varepsilon_j\varepsilon_{k+1}]$ 和 $E[(\varepsilon_i^2-\sigma^2)\varepsilon_{k+1}]$。它消不掉含干净坐标的项 $q_i\varepsilon_j$、$q_j\varepsilon_i$ 和 $2q_i\varepsilon_i$，所以二次块不是零。

- **常数行**：$E[\varepsilon_{k+1}]=0$，该行为 $0_{1\times r}$。

$\phi=0$ 时 $\Delta=0$，回到第 3.2 节白噪声下的交叉矩。

在同一批配对上定义干净矩

$$\bar G_0=\sum_{k\in P}z(q_k)z(q_k)^\top,\qquad C_0=\sum_{k\in P}z(q_k)q_{k+1}^\top,$$

以及 $O_{\mathrm{clean}}=\bar G_0^{-1}C_0$。E8 的理论对象是

$$O_{\mathrm{lim}}=\bar G_0^{-1}(C_0+\Delta)=O_{\mathrm{clean}}+\bar G_0^{-1}\Delta.$$

这个矩阵就是 $E[\hat G]^{-1}E[\hat C]$。有限样本恒等式

$$E[\hat G]^{-1}E[\hat C]=\bar G_0^{-1}(C_0+\Delta)$$

对任意有限 $n$ 成立。若 $n\to\infty$ 时

$$\bar G_0/n\to G_\infty,\qquad C_0/n\to C_\infty,\qquad \Delta/n\to\Delta_\infty,$$

其中 $G_\infty$ 非奇异，且噪声下的样本矩满足相应的大数定律，则

$$\hat O_{\mathrm{MC}}\xrightarrow{p} G_\infty^{-1}(C_\infty+\Delta_\infty).$$

此时 $O_{\mathrm{lim}}$ 收敛到同一极限。与第 4.2 节一样，Monte Carlo 均值在 $n$ 很大时接近上述期望之比，这是近似。该期望之比不是有限样本的 $E[\hat G^{-1}\hat C]$：$\hat G$ 与 $\hat C$ 相关，逆的期望不等于期望的逆。`theory.mc_limit_ar1(clean_trajs, sigma2, phi)` 返回 $O_{\mathrm{lim}}$。

在 AR(1) 噪声下，IV 的工具变量 $z(\tilde q_{k-1})$ 与 $\varepsilon_k$ 相关，因而无效；`iv2` 同样无效。E8 只做经验比较，不需要 IV 的理论公式。

## 7. 评价指标（定义必须严格一致）

设参考算子为 $O_{\text{ref}}$（S1 用 $O_{\text{true}}$，S2/S3 用 $O_{\text{clean}}$），估计算子为 $\hat O$。

| 指标 | 定义 |
|---|---|
| `err_O_rel` | $\|\hat O-O_{\text{ref}}\|_F/\|O_{\text{ref}}\|_F$ |
| `err_A_rel` | $\|\hat A-A_{\text{ref}}\|_F/\|A_{\text{ref}}\|_F$ |
| `err_H_rel` | $\|\hat H-H_{\text{ref}}\|_F/\|H_{\text{ref}}\|_F$ |
| `err_c_abs` | $\|\hat c-c_{\text{ref}}\|_2$（**用绝对误差**：$c_{\text{ref}}$ 可能接近 0，相对误差无意义） |
| `err_c_scaled` | $\|\hat c-c_{\text{ref}}\|_2/\text{RMS}(q)$，其中 $\text{RMS}(q)=\sqrt{\text{mean}\|q_k\|^2/r}$ |
| `specrad_hat`, `specrad_ref` | $\max|\text{eig}(\hat A)|$，$\max|\text{eig}(A_{\text{ref}})|$ |
| `specrad_err` | `specrad_hat − specrad_ref`（带符号；负值表示"虚假耗散"） |
| `ep_violation` | 能量守恒违反度，见下 |
| `rollout_err_h` | 视界 $h$ 的预测相对误差，见下 |
| `diverged` | 预测是否发散 |

**偏差与方差分解**（对 $R$ 个噪声重复）：对每个配置，$\bar O=\frac1R\sum_r\hat O^{(r)}$，

- `bias_O_rel` $=\|\bar O-O_{\text{ref}}\|_F/\|O_{\text{ref}}\|_F$
- `sd_O_rel` $=\sqrt{\frac{1}{R-1}\sum_r\|\hat O^{(r)}-\bar O\|_F^2}\,/\,\|O_{\text{ref}}\|_F$

A、H 两块同样计算。

**能量守恒违反度（只对 Burgers 型系统，S1、S2）。** Burgers 的非线性项满足 $\int u\,(u u_x)\,dx=0$。在 Fourier–Galerkin 降阶模型（S1）中，这意味着对任意 $q$ 都有 $q^\top H s(q)=0$。对测试快照 $\{q_k\}$：

$$\texttt{ep\_violation}=\frac{\text{mean}_k\,|q_k^\top\hat H s(q_k)|}{\text{mean}_k\,\|q_k\|\,\|\hat Hs(q_k)\|}.$$

S1 的真值应为机器精度量级。S2 中由于 POD 基不是 Fourier 基，$O_{\text{clean}}$ 本身也不严格满足，所以要同时报告 $O_{\text{clean}}$ 的值作为参照。

**预测误差。** 从**干净**测试初值 $\hat q_0=q_0$（S2/S3 中 $q_0=V^\top u_0$）出发迭代 $\hat q_{k+1}=\hat O^\top z(\hat q_k)$。

- S1：$\texttt{rollout\_err}_h=\|\hat q_{0:h}-q_{0:h}\|_F/\|q_{0:h}\|_F$；
- S2/S3：与**全阶真解**比较：$\|V\hat q_{0:h}-u_{0:h}\|_F/\|u_{0:h}\|_F$（Frobenius 范数对时间和空间一起取）。

**发散判定：** 出现非有限值，或 $\|\hat q_k\|_\infty>10^3\cdot\max_{\text{train}}\|q\|_\infty$。发散轨迹的误差记为 `inf`。对每个配置报告：
- 跨测试轨迹的**中位数**误差（`inf` 参与排序）；
- 非发散轨迹的**均值**误差；
- 发散比例。

**不要给发散设置惩罚分数。**

此外还需报告"POD 投影下限"：$\|VV^\top u-u\|_F/\|u\|_F$，即降阶秩 $r$ 下最好能达到的误差。

## 8. 秩–噪声的信噪比规则（RQ5，E4）

设 $\lambda_i=\text{mean}_k\,q_{k,i}^2$（干净训练数据上第 $i$ 个 POD 坐标的二阶矩，不中心化）。对 $\kappa_{\text{snr}}\in\{1,4,16,64\}$ 定义

$$r_{\text{snr}}(\sigma;\kappa_{\text{snr}})=\max\{i:\lambda_i\ge\kappa_{\text{snr}}\sigma^2\}.$$

E4 中对每个 κ 都报告 $r_{\text{snr}}$ 与经验最优秩 $r^*$ 的差。**不要事后只挑选表现最好的 κ 来报告**，四个都要列出。

## 9. 离散时间二次模型的采样间隔误差（RQ6，E7）

若连续时间系统为 $\dot q=f(q)$，$f$ 是二次多项式，则流映射

$$\Phi_{\Delta t}(q)=q+\Delta t\,f(q)+\tfrac{\Delta t^2}{2}\,Df(q)f(q)+O(\Delta t^3).$$

$Df(q)$ 是 $q$ 的仿射函数，$f$ 是二次的，所以 $Df\,f$ 是**三次**多项式。离散二次模型无法表示它，最优二次拟合的单步残差应满足 $\text{RMS}\propto\Delta t^2$。E7 用无噪声数据验证这个斜率。
