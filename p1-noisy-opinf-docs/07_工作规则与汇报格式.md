# 07 工作规则与汇报格式

## 1. 工作方式

- **按阶段推进，自主执行。** 阶段顺序见 `00` 第 6 节和 `04` 末尾。每完成一个阶段就写汇报，然后直接进入下一阶段。不需要等待批准，除非遇到下面第 3 节的情况。
- **小步提交。** 每个模块和对应测试写完、测试通过后就 git commit。
- **先测试，后实验。** `05` 中的测试全部通过之前，不跑 E1 及以后的实验。
- **规格优先。** 不要"改进"估计器、指标或实验设计。如果你认为规格有问题，在 `PROGRESS.md` 的"问题与建议"部分写出来，**同时仍按原规格执行**，除非问题属于第 3 节的停止条件。

## 2. 诚实性要求（不可违反）

1. 报告中的每个数字都必须来自 `results/` 中的文件，并由脚本读取后写入。不手抄，不四舍五入后再引用到别处。
2. 没有运行的实验，不报告结果；报告中写"未运行"及原因。
3. 发散、NaN、求解失败都按 `02`/`03` 的规则如实记录。不得通过更换种子、删除重复或调参来"消除"失败。
4. 不得在看到测试集结果后修改超参数、网格或估计器。如果确实需要修改（例如发现 bug），修复后**整个实验重跑**，并在 `PROGRESS.md` 中记录：修改了什么、为什么、旧结果的位置（旧结果移到 `results/_superseded/` 下，不删除）。
5. 用"支持 / 不支持 / 无法判断"描述结果与 `01` 中假设的关系，不使用"证明""显著优于"等措辞，除非有对应的统计量支持。

## 3. 必须停下来问负责人的情况

只有以下情况才暂停并等待回复：

1. 远程机器无法登录，或目标目录 `Desktop\projects\p1-noisy-opinf` 已经存在；
2. 需要安装 `requirements.txt` 以外的包，或需要修改全局环境；
3. `02` 中的某个公式与单元测试结果矛盾，且你确认不是实现错误（附最小复现例子）；
4. E0 中求解器验收按 `03` 规定的调整顺序全部尝试后仍不通过；
5. 某个实验按 `04` 第 1.6 节缩减后，估算耗时仍超过 8 小时；
6. 磁盘剩余空间少于 5 GB。

其他问题（小 bug、绘图细节、性能优化）自行解决，并在汇报中写明。

## 4. 阶段汇报格式（追加到 `reports/PROGRESS.md`）

```markdown
## [阶段名，如 "E2 完成"] — YYYY-MM-DD HH:MM（远程机器本地时间）

**远程 git commit：** <hash>
**做了什么：** 3–5 条要点
**测试状态：** pytest 通过数 / 总数
**实验运行：** 配置数、重复数、总耗时、失败行数（status != ok）及原因
**关键数字（由脚本从 results/ 读取后填写）：**
| ... | ... |
**与规格的偏离：** 无 / 列出每一项（改了什么、为什么）
**问题与建议：** 无 / 列出
**下一步：** ...
**日志末尾：**
​```
<最后 50 行>
​```
```

"关键数字"由一个小脚本 `scripts/progress_snippet.py --exp e2` 生成，不要手写。每个实验的关键数字：

| 实验 | 关键数字 |
|---|---|
| E0 | 各验收项的通过情况和数值 |
| E1 | 每个配置的 `theory_gap_rel`（A、H） |
| E2 | n_train=30 时各估计器在每个 rho 下的 `bias_A_rel`、`bias_H_rel`、`rollout_med` 中位数、发散比例 |
| E3 | 同上（basis=noisy，σ²=est_trailing）；σ² 估计的相对误差中位数 |
| E4 | 每个估计器的 $r^*_{\text{val}}$ 和 $r^*_{\text{noisyval}}$ 随 rho 的变化；四个 κ 的 $r_{\text{snr}}$ |
| E5 | 每个 r 的 `closure_rel` 与 IV 偏离；第 2 部分的三种距离 |
| E6 | 同 E3，每个 r |
| E7 | 斜率及 95% 区间 |
| E8 | 每个 φ 下各估计器的 `bias_O_rel`；S1 上 `mc` 的 `theory_gap_rel` |

## 5. 代码风格

- 类型注解，函数 docstring 说明形状（例如 `Q: (n, r)`）。
- 不写超过 60 行的函数，配置用 YAML 而不是硬编码。
- 不留被注释掉的旧代码。
- `README.md` 写清楚：环境、如何跑测试、如何依次跑 E0–E8、如何生成图和报告、每个实验大约耗时多久（实测值）。
